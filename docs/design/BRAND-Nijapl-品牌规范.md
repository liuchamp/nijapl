# Nijapl 品牌规范 v1.0

> JLPT N3 词汇学习 App（Lynx 跨平台）｜定稿日期：2026-09-12
> 视觉资产画布：`nijapl-brand.miora`（项目根目录）

---

## 一、品牌基础

| 项 | 内容 |
|---|---|
| 品牌名 | **Nijapl**（标准字固定拼写、首字母大写，不得写作 NIJAPL / nijapl） |
| 定位 | JLPT N3 词汇学习 · 日系清新 |
| 品牌风格关键词 | 柔和渐变 · 圆润几何 · 大留白 · 低饱和樱粉/鼠尾草绿 |
| 定稿 Logo | 「负空间 N」——圆角方块 + 粉→绿柔和渐变 + 负空间 N |

### Logo 定稿说明

- 构成：圆角方块（圆角约为边长 22%）内以负空间切出字母 N，粉（左）→ 鼠尾草绿（右）对角渐变。
- 标准字：几何圆润无衬线、Title Case（Nijapl）、中字重，深靛蓝。
- 最小尺寸：纯标志 24px、组合标志（含标准字）64px 宽；低于此尺寸只使用纯标志。
- 安全区：标志四周留白 ≥ 标志边长的 12%。
- 禁用：不得拉伸变形、不得改用高饱和色、不得加投影/描边、不得放在低于 3:1 对比度的背景上。

## 二、色彩体系

| 角色 | 名称 | 色值 | 用途 |
|---|---|---|---|
| 主色 | Sakura 樱粉 | `#F5A8BC` | 主按钮、强调、打卡/奖励场景 |
| 主色深 | Sakura 500 | `#EE87A2` | 按钮按压态、图标点缀 |
| 辅色 | Sage 鼠尾草绿 | `#8FB89B` | 进度、正确/完成、复习场景 |
| 辅色浅 | Sage 300 | `#A9CBB2` | 进度环底色、卡片点缀 |
| 文字/标准字 | Indigo 靛蓝 | `#3B3B6D` | 标题、正文主色、标准字 |
| 卡片/点缀 | Periwinkle 浅靛 | `#9AA3D8` | 次级卡片、图表第三色 |
| 页面底色 | Cream 米白 | `#FAF6EC` | 全局背景（禁止纯白） |
| 分隔/弱文字 | Indigo 30% | `#3B3B6D4D` | 说明文字、分割线 |

渐变规范：主渐变为 樱粉 `#F5A8BC` → 鼠尾草绿 `#8FB89B` 对角线（135°），中间过渡经过灰调藕色，禁止中段出现过饱和紫。

## 三、字体系统

| 用途 | 字体栈 |
|---|---|
| 标准字 / 西文 | Nunito、Quicksand 同类的几何圆润无衬线（Medium） |
| 日文假名/汉字 | Noto Sans JP / 系统日文字体 |
| 中文 UI | 系统默认（PingFang SC / MiSans），与靛蓝文字色搭配 |

## 四、图标规范（`src/assets/icons/`）

已交付 18 个线性图标：`home / stages / study / review / graph / book / settings / audio / star / search / chevron-left / chevron-right / close / check / calendar / flame / trophy / plus`

- 网格：24×24，内容缩进 2px
- 描边：2px，圆头（round cap / round join），不填充
- 颜色：`currentColor`（跟随文字色，默认靛蓝 `#3B3B6D`）
- 语义色例外：check → Sage 绿（正确）、flame → Sakura 粉（打卡热力）
- 新增图标必须沿用同一网格与描边规格，保持成套

## 五、插图规范（空状态 / 成就）

生成插图（画布「插图」区）遵循：

- 扁平、圆角几何、米白底、大留白，无描边或极浅投影
- 色板严格取自第二节；点缀假名时只用白色
- 不出现 Logo、不出现可读单词（假名仅作装饰纹样）

## 六、App 启动图标

- 主图：1024×1024（画布「App 启动图标」），标志全出血、负空间 N 居中
- 各平台派生尺寸（180/152/120/96/72/48 等）从主图等比缩放生成，不得重新构图
- Android 自适应图标：将标志缩小至安全区（约 66%）置于纯米白 `#FAF6EC` 底上
