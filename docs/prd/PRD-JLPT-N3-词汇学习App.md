### 1.1 原始需求复述

把 JLPT N3 的**词汇与语法**做成一个移动端学习应用，需满足 5 条原始需求：

1. **词汇学习功能** —— 能按规划逐阶段学词。
2. **点击词汇可以发音** —— 点词/点句即读。
3. **按规划阶段看学习进度** —— 阶段 / 模块 / 词条三级进度可视化。
4. **词汇与语法可详解，并在适当时候跳转** —— 详解页 + 跳转时机规则（不是让用户自己找）。
5. **脑图呈现关联知识点** —— 知识图谱页，节点可点并跳转。

### 1.2 已拍板决策（不可推翻）

| # | 决策 |
|---|------|
| D1 | **运行时 = Lynx 跨平台**，同一套代码可打包 H5（Lynx for Web） |
| D2 | **例句数据 = 自建 + AI 生成**（走离线流水线，不进端内） |
| D3 | **v1.0 范围保留 P6 知识图谱三视图 + P4 语法 Tab** |

### 1.3 本 PRD 相对 v1.1 的收敛说明

本 PRD 以 v1.1 为骨架**收敛整合**，不重新发明 IA/规则/数据模型；核心增量是**解决「四份数据源文件彻底不存在」这一阻断问题**：v1.0 采用 **seed 种子数据**方案（见 §七），使 10 页面 + 4 引擎可在数据未到位前**全部跑通、可测、可演示**，且真实数据到位后**页面与引擎代码零改动**。

## 三、目标用户与核心场景

### 3.1 目标用户

- **主用户**：备考 JLPT N3 的日语学习者（N5/N4 基础已具备），需要在碎片时间系统刷词、复习、查语法。
- **次用户**：已过 N3 想巩固的学习者（以复习 + 图谱关联为主）。

### 3.2 核心用户故事

| # | As a | I want | So that |
|---|------|--------|---------|
| US1 | 备考中的学习者 | 打开 App 就告诉我"今天学什么、学到哪了、还差多少" | 不用自己做计划就能马上开始 |
| US2 | 学习者 | 学习时点一下就听到发音，并能自评认识/模糊/不认识 | 边学边记，系统帮我安排复习 |
| US3 | 学习者 | 遇到不认识的词时自动弹出详解，而不是我自己去找 | 降低查词成本，学习不断链 |
| US4 | 学习者 | 在详解里点例句里的生语法就能跳进语法详解 | 把"词"和"语法"连起来理解 |
| US5 | 学习者 | 用脑图看到词/语法/模块之间的关系，并可点节点跳转 | 理清关联，形成知识网络而不是孤立记忆 |

### 5.2 站点关系（文字描述）

- **P2 是流量枢纽**：P0（继续学习）、P1（选模块）、P7（开始复习）三条主路径都汇入它。

### 5.3 逐页设计

#### P0 首页 · 学习仪表盘（Tab）
- **定位**：打开即知「今天学什么、学到哪、还差多少」。
- **关键区块**：
  1. 顶部栏：今日日期 + 连续打卡 N 天 + 今日目标进度环（如 24/40 词）
  2. 继续学习卡：读 **SESSION** 快照（阶段/模块/第 N 词）→ 一键续学 → P2
  3. 阶段进度条：4 段横向（含冲刺期，标注"纯复习"）→ 点击进 P1
  4. 今日任务：新学 20 + 复习 35 + 语法 2，各自可点直达（P2/P7/P4）
  5. 薄弱预警：错词 ≥3 次的 TOP5 → 点进 P7
  6. **知识图谱入口卡**（显性，修复可发现性）
- **主要交互**：点继续学习卡 → P2；点阶段条 → P1；点今日任务项 → 对应页；点图谱卡 → P6。

#### P1 阶段地图（Tab）
- **定位**：全局进度树，解答「还差多少」。
- **关键区块**：树形 **4 阶段 → 模块 → 词条数**；节点五态（🔒未解锁／⬜未学／🟡学习中／✅已掌握／🔴需强化）。
- **主要交互**：
  - 点模块 → P2；长按模块 → P6 看该模块脑图（保留但**非唯一入口**）。
  - 冲刺期节点：`hasContent=false`，完成度不参与计算，文案「冲刺期 · 纯复习」。
  - 解锁规则：上一**含词**阶段完成度 ≥ 80%（可在 P9 关闭）。

#### P2 词汇学习（核心页，二级）
- **定位**：词汇学习主战场 + 全产品流量枢纽。
- **关键区块**：
  - 顶部：模块名 + 进度 12/27 + 发音开关 + 退出
  - 卡片正面：假名超大字 + 汉字 + 词性徽章
  - 卡片背面：中文释义 + 例句（整句可点朗读 + 语法高亮）
  - 底部三档按钮：不认识（红）／模糊（黄）／认识（绿）
- **主要交互**：
  - **点击卡片任意位置 → 发音**（整卡热区）
  - **滑动 = 翻页**（原生 `<viewpager>`，Web 降级为横向 `<scroll-view>`）
  - **跳过 = 显式按钮**（走 `applySkip`，不计分、**不写入 `history`**）
  - 上滑看详解 → P3；双击发音
  - 点例句中的生语法 → P5
  - 本模块学完 → 弹「本模块知识脑图」→ P6

#### P3 词汇详解（二级）
- **定位**：单词全档案。
- **关键区块（自上而下）**：读音与汉字 → 词性与活用（动词给变形表）→ 中文释义 → **例句（TTS + 语法高亮）** → 关联语法 chips → P5 → 关联词 chips → 自身/P6 → 记忆状态时间线。
- **主要交互**：点读音/例句 → C1；点关联语法 → P5；点关联词 → P3 自身；点「查看关系图」→ P6；「加入复习」→ P7。

#### P4 语法列表（Tab）
- **定位**：句型检索入口。
- **关键区块**：句型列表，支持按**周次 / 层级**筛选；长列表用 `<list>` 保性能。
- **主要交互**：点句型 → P5。

#### P5 语法详解（二级）
- **定位**：句型全档案。
- **关键区块**：句型大字 → 接续规则 → 场景标签 → **例句（TTS）** → 近义句型辨析表 → 涉及词汇 → 掌握度自评。
- **主要交互**：例句朗读 → C1；近义辨析 → P5 互跳；涉及词汇 → P3；「打开脑图」→ P6。

#### P6 知识图谱（二级，显性入口）
- **定位**：需求 5 的落点，横向串联词/语法/模块。
- **三视图**：

| 视图 | 内容 | 入口 |
|------|------|------|
| 全景脑图 | 阶段 → 模块 折叠展开 | P0 卡片、P1 模块长按/P3/P5 按钮 |
| 词条局部图 | 中心词 → 近义/反义/同模块/派生/相关语法 | P3「查看关系图」 |
| 语法关系图 | 句型 → 上位/下位/近义/对立 | P5「打开脑图」 |

- **Lynx 落地约束（硬约束，需求方不得要求 DOM 方案）**：Lynx 的 `<svg>` 是**静态整体渲染**（整段 SVG 字符串 → 单个 native view，**无子节点事件**），因此**不能用 mermaid.js**。方案：
  - 画边/连线：`<svg content={svgString}>` 作**背景层**（静态，性能好）
  - 节点可点：节点用**绝对定位 `<view>`** 叠在 SVG 上层，`bindtap` / `bindlongpress`
  - 双指缩放：外层容器 `transform: scale()` + 手势（`'main thread'` 主线程脚本保证跟手）
  - 聚焦高亮：选中节点时重算 SVG 字符串（换色）+ 其余节点降透明度
  - 布局：预计算（构建期）或运行期轻量力导向（**不依赖 DOM**），坐标写入节点定位
- **主要交互**：点词节点 → P3；点语法节点 → P5；点模块节点 → P2。
- 交互指标口径：不承诺"自由度极高的画布"，而是**"可缩放、可点、可聚焦"**。

#### P7 复习（Tab）
- **定位**：今日待复习 + 错词本。
- **关键区块**：今日到期队列（读 `srs`）、错词本（`需强化` 状态聚合）、开始复习按钮。
- **主要交互**：开始复习 → P2（走复习模式）。

#### P8 自测（二级）
- **定位**：检验掌握度。
- **关键区块**：题型切换（日→中 / 中→日 / 听音选词）、答题区、结果回流。
- **主要交互**：听音选词按钮 → C1；查看解析 → P3。

#### P9 我的（Tab）
- **定位**：设置与数据面板。
- **关键区块**：发音设置（语速 0.5–1.5、音调、卡片出现即读、试听）、学习目标、统计、解锁规则开关、数据导出。
- **主要交互**：试听 → C1；各设置项即时生效并持久化。
- **注**：**移除 v1.0 的「读音选择（训读/音读）」** —— TTS 层不支持指定读音，改为恒按 `kana` 朗读。

#### C1 全局 TTS 播放器（组件）
- **定位**：单例语音端口，跨页调用。
- **端口**：`src/engine/tts/` → `index.ts`（`speak(text, opts)` / `stop()` / `getVoices()`）+ `tts.native.ts`（NativeModule「TTSEngine」）+ `tts.web.ts`（`speechSynthesis`）。
- **硬约束**：Lynx **无 `<audio>`**、无内置 TTS；原生端走 Native Module（iOS `AVSpeechSynthesizer` / Android `TextToSpeech(Locale.JAPANESE)`）；H5 走 `speechSynthesis`。
- **降级**：预置音频 mp3 → **同样经 Native Module 播放器**（Lynx 无 `<audio>`）；微信内置浏览器不支持 `speechSynthesis` → 明确提示「当前浏览器不支持语音，建议用 App 或系统浏览器打开」+ 提供「复制假名」。
- **iOS**：首次调用须在用户手势内，首屏做一次静音解锁；P9 提供「试听」。
- **音色**：不硬编码音色名，按语言前缀 `ja` 过滤 + `voiceschanged` 兜底。

#### C2 详解跳转浮层（组件）
- **定位**：「查看详解」半屏引导。
- **触发**（见 §5.4 规则）：首次遇词自评不认识 → 自动展开；连错 ≥2 次 → 弹引导。
- **交互**：确认 → P3；忽略 → 继续下一张。

### 5.4 跳转触发规则（需求 4 的"适当时候"）

落地为 `src/engine/jumpRules.ts` 配置，**6 条规则**：

| # | 触发时机 | 条件 | 动作 | 目标 |
|---|---------|------|------|------|
| J1 | 首次遇词 | `word.seen === false` 且自评「不认识」 | 自动展开详解浮层 | P3 |
| J2 | 连续答错 | `word.wrongCount >= 2`（**会话内累计**） | 弹「要不要看看详解」 | P3（确认后） |
| J3 | 例句含生语法 | `grammar.learned === false` | 语法高亮 + 下划线 | P5（点击后） |
| J4 | 模块学完 | `learned / total === 1` 且 `total > 0` | 弹「本模块知识脑图」 | P6 |
| J5 | 词性为动词 | `pos ∈ POS_VERB`（**显式枚举**，见 §七.4） | 详解页附「变形表」 | P3 内锚点 |
| J6 | 存在关联词 | `word.related.length > 0` | 详解页显示关联 chips | P3 → P3 |

> **实现红线**：`POS_VERB` 必须用**显式枚举映射表**（`['五段動詞','一段動詞','サ変動詞','カ変動詞','不規則動詞']`），**不得**用 `pos ∈ {五,一,サ,不}` 单字匹配（会漏判/误判），并配单元测试。

### 5.5 词条状态机（SRS）

五态（**统一术语，全项目只用「需强化」**）：

| 状态 | 含义 | 判定 |
|------|------|------|
| 未学 | 从未出现 | 初始态 |
| 学习中 | 首次出现后 | 首次作答 |
| 模糊 | 自评"模糊"或复习答错 | `wrongCount < 2` |
| 需强化 | 自评"不认识"或连续错 ≥2 | `wrongCount >= 2` |
| 已掌握 | 自评"认识"或复习答对 | 进入长间隔 |

- 间隔序列：10 分钟 / 1 天 / 3 天 / 7 天 / 15 天 / 30 天。
- 补「**跳过**」分支：`学习中 → 未学`（点「跳过」按钮，**不计分、不写入 `history`**，故跳过后再遇仍算「首次遇词」）。
- `已掌握 → [*]` 的语义为「**该阶段全部词条掌握**」（一个词只属于一个阶段）。
- `wrongCount` 口径：会话内累计；跨会话累计值存于 `PROGRESS.wrongCount`。
- J1 只对 `word.seen === false` 触发，会话内重复不再打断。

## 七、数据方案（本 PRD 重点章节）

### 7.1 前提：四份数据源文件不存在

v1.1 引用的四份数据源文件 —— `JLPT-N3-词汇总表-Anki.csv`、`JLPT-N3-第一/二/三阶段词汇表.md`、`JLPT-N3-语法句型总表.md`、`JLPT-N3-备考计划.md` —— 在仓库及整个磁盘（Downloads/Desktop/Documents/workspace）**均已确认不存在**。因此 v1.1 §二 的 **992 词 / 230 句型 / 41 模块**等规模数字**当前不可核验**。

### 7.2 v1.0 采用方案：**seed 种子数据**

- 造一份**结构完整、规模较小**的种子数据集，字段与「真实数据 JSON schema」**完全一致**。
- 规模目标：**4 个阶段 / 约 8–12 个模块 / 约 40–60 个词条 / 约 12–20 个语法点 / 配套例句**。
- **每条数据标记 `source: "seed"`**，使 10 个页面与 4 个引擎**全部可跑通、可测试、可演示**。
- **严禁伪造**：不得把种子数据描述成"真实的 JLPT N3 992 词表"。文档、UI 文案、埋点中一律标注「**当前为种子数据**」。

### 7.3 数据管线脚本职责（离线 Node 脚本）

| 职责 | 说明 |
|------|------|
| 生成 | 从 `data/source/`（或 seed 输入）产出 `data/build/{stages,modules,words,grammar,sentences}.json` |
| 校验 | schema 校验（字段/类型/必填）、引用完整性（`stageId`/`moduleId`/`grammarId` 均存在）、枚举合法性（`pos` ∈ 词性枚举、`source` ∈ {seed, ai, human}） |
| 例句校验（真实数据阶段） | 含目标词/语法、形态正确、难度不越级、标注完整、去重；人工抽检 10%，错误率 < 2% 方可入库 |
| 一键执行 | 单命令产出 + 校验，CI 可复现 |

### 7.4 关键 schema 与枚举

**实体（与 v1.1 §八 一致）**：`STAGE` / `MODULE` / `WORD` / `GRAMMAR` / `SENTENCE` / `SENTENCE_WORD` / `SENTENCE_GRAMMAR` / `WORD_RELATION` / `GRAMMAR_RELATION` / `PROGRESS` / `SESSION`。

关键字段要点：

- `STAGE.hasContent`：冲刺期 = `false`，**所有完成度计算短路为不参与**（避免 0/0 = NaN）。
- `WORD.kana`：**TTS 朗读依据**（恒按假名朗读）。
- `WORD.pos`：**显式枚举**。`POS_VERB = ['五段動詞','一段動詞','サ変動詞','カ変動詞','不規則動詞']`（**待与真实数据实际取值核对，见 §九**）。
- `SENTENCE.source`：`seed | ai | human`；`reviewStatus`：`pending | approved`。
- `SENTENCE_WORD.surface`：该词在句中的形态（供语法高亮/含目标校验）。
- `PROGRESS.state`：`未学 | 学习中 | 模糊 | 已掌握 | 需强化`。
- `SESSION`：`stageId / moduleId / lastWordIndex`（断点续学）、`lastStudyDate`（打卡）、`todayNewCount / todayReviewCount`（配额）。

### 7.5 真实数据替换路径（零代码改动）

```
1. 把 4 份源文件放入 data/source/
2. 运行数据管线脚本（离线）→ data/build/*.json
3. 校验通过后，替换构建期打入 bundle 的数据文件
4. 页面与引擎代码 0 改动（仅数据文件的 source 字段由 seed 变为 ai/human）
```

> 这一路径是 v1.0 数据方案的核心承诺：**seed 与真实数据共用同一 schema，替换即生效**。

## 八、验收标准

> 对照 v1.1 §十二，**只保留可控指标**，不写"200ms 内出声"这类受系统/浏览器制约的项。

| 需求 | 验收点（可控指标） |
|------|------------------|
| 1 词汇学习 | 从首页 **≤3 次点击**开始任一模块；三档自评后进度实时更新（单测覆盖 `progress`）；断点续学命中 100% |
| 2 点击发音 | 点击整卡热区 **≤100ms 内出现视觉反馈**；音频起播中位延迟：原生 ≤300ms、H5 视浏览器而定；**不支持 TTS 的环境给出明确提示（不得静默失败）** |
| 3 阶段进度 | 阶段/模块/词条三级完成度与本地数据一致（**误差 0，单测覆盖**）；冲刺期不参与计算且不报错 |
| 4 详解跳转 | 6 条 `jumpRules` 均有可复现用例；首次不认识 → 自动详解；连错 2 次 → 引导；例句语法可点进 P5 |
| 5 知识脑图 | 三视图在全量数据规模下**首屏 ≤1.5s**；节点点击跳转正确；**可缩放、可点、可聚焦**；已掌握节点有视觉区分 |
| 6 数据质量 | seed 数据集结构完整、校验 100% 通过；真实 AI 例句阶段：抽检错误率 **< 2%**，含目标词/语法校验通过率 100% |
| 7 人工验收项 | **日语音色听感**由人工验收（不自动判定）；微信内置浏览器 TTS 降级提示人工确认 |
