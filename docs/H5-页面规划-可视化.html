三、页面关系总图（站点地图）

图 1 · 站点地图与导航关系
Tab 主页面 二级页面 全局组件
关系要点
• P2 是流量枢纽：首页、阶段地图、复习三条主路径都汇入它，所有学习行为在此发生。
• P3 / P5 是知识沉淀层：出口一律是 P6（图谱）或回到 P2，不再外扩。
• P6 是连接器：不生产内容，只把 P2 / P3 / P5 横向串起来，是需求 5 的落点。
• C1 横切所有页面：发音不是某一页的功能，而是全局能力。

八、发音方案（需求 2）

层级方案说明
首选Web Speech API speechSynthesis，lang="ja-JP"零成本零体积，iOS / Android / Chrome 均支持
增强优先挑选 Google 日本語 / Otoya / Kyoko 等 ja 音色音色列表在 P9 可切换
降级音色缺失时提示安装日语语音包，允许预置 mp3保证不出现「点了没声音」
关键坑iOS Safari 必须在用户手势内首次调用首屏静音解锁 + P9 提供「试听」

可配置项（P9）：语速 0.5–1.5、音调、卡出现即读、训读/音读选择。

交互设计：发音热区 = 整张卡片，不只是小喇叭图标；例句整句也可点朗读。

项选型理由

需求验收点
1 词汇学习3 次点击内开始任一模块学习；三档自评后进度实时更新
2 点击发音点卡片热区 200ms 内出声；日语音色正确；无声环境有明确提示
3 阶段进度三级完成度与本地数据一致，误差 0
4 详解跳转首次不认识→自动详解；连续错 2 次→引导详解；例句语法可点进 P5
5 知识脑图三视图均可渲染，节点点击正确跳转，已掌握状态有视觉区分
