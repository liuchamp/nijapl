## 2. 重点攻击面（至少 13 条，含已知高危）

1. **J1 × skip × history（最高危）**：N1/N2 与 O1/O2 冲突面。攻：跳过后 `history` 不增、再展示+不认识仍触发 J1；已作答后不再触发。也要断言**工程师自测已翻转**（否则两套测试打架）。
2. **端口永不 throw / 零静默失败**：用抛错的假 `NativeModules` / 假 `speechSynthesis` 注入，断言 `getCapability/speak/stop/getVoices` 全部不 throw 且返回判别联合；空 `getVoices` 但平台已上报语音时 `speak` 返回 `no-ja-voice`。
3. **`NativeModules` 收敛**：全仓扫描，命中集合必须 ⊆ `{typing.d.ts, tts.native.ts, storage.native.ts}`（T05 新增文件不得引入）。
4. **hydration 门控与看门狗**：`hasHydrated()` 初始 false → 恢复后 true；`App` 未恢复渲染启动态（不闪默认态）；`persist` 分片不含 `runtime`；看门狗超时兜底可达 `hydrated=true`。
5. **冲刺期无 NaN**：`hasContent=false` 阶段完成度=哨兵；`overall` 忽略哨兵；全冲刺 → 0；`Number.isFinite` 全绿。
6. **解锁规则**：上一**含词**阶段 ≥80%；`hasContent=false` 阶段被跳过；规则关 → 全解锁；首阶段恒解锁；无死角。
7. **≤3 击**：首页 → 模块学习路径计数（继续学习 / 阶段条 / 今日任务）。
8. **P6 图谱**：断言**不含** mermaid/d3-dom/canvas；三视图纯函数链路可跑；`layout` 确定性；`'main thread'` 内无 `NativeModules`。
9. **P9**：**不得存在**「读音选择（训读/音读）」；设置持久化生效（改 rate → 重载仍在）。
10. **P4**：`<list-item>` 的 `item-key` 与 `key` 一致。
11. **滑动语义（N3）**：`enable-scroll` 不得为 `false` 致无法翻页；页面不得把 `classifySwipe` 的 `left` 直连 `skipWord`；存在显式跳过按钮 → `skipWord`。
12. **每日配额（N4）**：`DAILY_NEW_GOAL=20 / DAILY_REVIEW_GOAL=35 / DAILY_GRAMMAR_GOAL=2` 存在且被首页/语法页引用。
13. **跨天打卡**：`rollSessionDay` 同日不变、隔日 +1、断档归 1；`toDateString` 用本地日期；配额跨天重置。
14. **迁移健壮性（补充）**：`migrateState` 对 `null`/字符串/嵌套坏对象返回安全默认，不 throw。

## 7. 我认为最可能藏缺陷的 3 处

1. **J1 × 跳过 × history 的语义边界（N1/N2）**：三处独立改动（`applySkip`、`isFirstEncounter`、工程师自测）需同时对齐，任一漏改都会让 scenario (b) 或 (c) 失败；且旧测试与新口径直接冲突，最易「假绿/假红」。
2. **滑动/翻页与跳过的耦合（N3）**：`enable-scroll`、`viewpager` 与 `swipe.left→skip` 三处曾互相牵制，最易残留「左滑仍跳过」或「滑动被禁用」的回归。
3. **hydration 门控 × 异步端口 × 看门狗**：`persist` 异步 rehydrate、`onRehydrateStorage`、`setTimeout` 看门狗三者时序在 Node / 真机 / Web 下差异大，易出现「卡启动态」或「闪默认态」。
